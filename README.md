# Проект: Сбор и синхронизация телеметрии с помощью ModbusTCP и SQLite

Данный проект состоит из двух основных процессов:
1. Опрос ModbusTCP-устройства и сохранение данных в локальную базу SQLite.
2. Синхронизация накопленных данных с удалённым сервером по HTTP (REST API).

## Структура проекта
```bash
├── main.py              # Основная логика (запуск процессов sync_data и modbus_tcp_client)
├── config_read.py       # Загрузка конфигурации из переменных окружения (.env)
├── .env.example         # Шаблон файла с переменными окружения
├── requirements.txt     # Список зависимостей
├── .gitignore           # Файлы и каталоги, исключаемые из Git
└── README.md            # Документация проекта
```

## Структура проекта
Настройка и запуск

```bash
pip install -r requirements.txt

cp .env.example .env

python main.py

```
